# 소비 습관 분석기

지출 CSV를 읽어 월·카테고리별 지출과 월 예산 사용률을 보여 주는 Streamlit 대시보드. LLM·API 키 없이 코드 계산만으로 동작합니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 사용법
1. 사이드바에서 지출 CSV 선택 (`data/` 폴더 목록 또는 직접 업로드)
2. 월별 예산 CSV 선택 (선택 사항)
3. 월·카테고리를 바꾸면 표·차트·건수·총지출이 함께 바뀜. 예산 현황은 카테고리와 무관하게 그 달 전체 기준

## 파일
- `app.py` 화면 / `analysis.py` 검증·계산 (화면과 분리)
- `data/` 수업용 합성 자료 (원본은 읽기만 하고 수정하지 않음)

## 검증 규칙 요약
- 지출 CSV: UTF-8(BOM 허용), 필수 열 5개, 줄마다 날짜·금액·거래ID 중복·카테고리·사용처 검사. 오류가 하나라도 있으면 분석을 멈추고 줄 번호별 이유만 표시
- 예산 CSV: 월 중복·음수·`YYYY-MM` 형식 검사. 오류여도 지출 분석은 계속
